## Decisiones abiertas

1. **`blocks:` vs `steps:`** en rutinas: se adopta `blocks:` (con `kind` y `ref`) y se lee `steps:` como alias. ¿OK?
2. **Plantillas de área vs plugins:** ¿un solo sistema (`.rumbo/plugins/`) o dos?
3. **Estados de objetivo:** ampliar `active · done · paused · dropped` con `not-started` y `failed`.
4. **Nivel de ejercicio:** la spec usa 1-3; tu ruta de Java usa 1-4. Se mantienen los dos (nivel = número).
5. **ADR nuevos a escribir:** contador de tareas, rutinas con bloques, coach por reglas, propuestas IA en `.rumbo/`, sync/móvil (cuando toque).
