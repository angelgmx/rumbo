# 0003. El tipo de nota lo dice el frontmatter, no la carpeta

- **Estado:** aceptado
- **Contexto:** cada persona organiza su vault a su manera (PARA, Johnny Decimal, sin carpetas…).
- **Decisión:** el campo `type` dice qué es una nota. Las carpetas son solo sugerencias configurables.
- **Consecuencias:** funciona con vaults que ya existen. Las notas sin `type` son notas normales.
