# Flujo de trabajo

Cómo se usa Rumbo de principio a fin. Cada pantalla existe para un paso de este flujo; si una pantalla no sirve a ningún paso, sobra.

## La jerarquía

```
Objetivo            qué quieres lograr y para cuándo
├── Roadmap         lo que aprendes      → Módulos → (apuntes · ejercicios · recursos) → Tareas
├── Proyecto        lo que construyes    → Hitos → Tareas
└── Hábito          lo que repites       → Registro de cada día

Rutina              un hueco fijo de tiempo (en el Calendario) que junta hábitos y estudio de un roadmap
Tarea               lo que se hace un día concreto; la unidad de todo
```

Todo lo que haces cuelga de un objetivo. Una tarea sin objetivo es mantenimiento (comprar pan) o un objetivo que aún no has escrito.

## Los cinco pasos

| # | Paso | Pregunta | Dónde | Qué haces |
|---|---|---|---|---|
| 1 | **Decidir** | ¿Qué quiero lograr? | Objetivos | Creas el objetivo: nombre, área, fecha límite, por qué y resultados clave |
| 2 | **Planear** | ¿Cómo llego? | Panel del objetivo → «Cómo llegas» | Conectas o creas un roadmap, un proyecto o un hábito. El roadmap trae sus módulos; el proyecto, sus hitos y tareas |
| 3 | **Encajar** | ¿Cuándo lo hago? | Calendario | Creas rutinas (hueco fijo: «Estudio Java L-V 17-19») y pones fecha y hora a las tareas. La IA coloca las tareas sueltas en huecos libres |
| 4 | **Hacer** | ¿Qué hago ahora? | Foco | Pulsas **Empezar**: te lleva al módulo o tarea, corre el temporizador y al acabar **Siguiente** |
| 5 | **Revisar** | ¿Voy bien? ¿Llego? | Foco (cerrar el día) · Objetivos · Métricas | Cierras el día, ves el progreso que sube y si llegas a tiempo; ajustas si no |

## Cómo sube el progreso

```
paso de tarea ✓ → tarea hecha → módulo dominado → roadmap → objetivo
                              → hito / proyecto ────────────→ objetivo
registro de hábito ✓ → racha → (hábito del objetivo) ─────────→ objetivo
```

Nada se escribe a mano dos veces: el progreso se calcula de abajo arriba.

## Entradas laterales (siempre a mano)

| Entrada | Qué hace | Dónde acaba |
|---|---|---|
| **Captura rápida** (`Ctrl N`) | Apuntas algo sin pensar dónde va: tarea o idea | Inbox o Ideas |
| **Organizar con IA** | Propone dónde va cada tarea suelta: objetivo, proyecto, fecha, pasos | La tarea en su sitio |
| **Ideas** | Lo que aún no es una tarea | Se convierte en tarea, proyecto u objetivo |
| **Notas** | El conocimiento (Markdown en el vault) | Enlazado desde módulos, proyectos y objetivos |

## Reglas del flujo

- **Crear desde el contexto.** Una tarea creada dentro de un proyecto ya es de ese proyecto; un roadmap creado desde un objetivo ya está conectado. No hay que volver a elegir.
- **Un solo sitio para cada cosa.** El detalle siempre es un panel lateral; editar es en su sitio.
- **Lo siguiente siempre visible.** Cada objetivo, roadmap y proyecto dice cuál es su siguiente paso.
- **La IA propone, tú decides.** Siempre con vista previa y deshacer.
