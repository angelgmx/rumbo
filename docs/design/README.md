# Diseño

Las láminas son la referencia visual: la app tiene que parecerse a esto. Si una pantalla no está aquí, primero se diseña (maqueta y aprobación) y después se programa.

Antes de diseñar o programar una pantalla, lee [flujo.md](flujo.md) (a qué paso sirve) y [guia.md](guia.md) (con qué piezas se hace).

**Estética:** raíl de iconos a la izquierda, tarjetas con luz y sombra suave, paneles laterales flotantes para el detalle, bermellón `#FF5B2E` como único acento, Geist y Geist Mono, ilustraciones planas sin personas. Cada pantalla responde a una sola pregunta.

**Raíl:** Foco · Tareas · Calendario · Hábitos · Objetivos · Proyectos · Roadmaps · Conocimiento · Métricas · Ejercicios · Áreas, con Ajustes abajo. Las rutinas viven en el Calendario y no hay página Visión. Notas pasa a llamarse Conocimiento. La IA se abre desde cualquier pantalla con `Ctrl J`.

Claves del diseño vigente:

- **Tareas:** el panel de la tarea va por secciones (Descripción · Cuándo · Dónde · Esfuerzo · Pasos · Recursos). El progreso se mide por pasos y el tiempo real por sesión; ya no hay contadores.
- **Calendario:** las fuentes (Inbox, Sin fecha y áreas) abren un panel secundario de tarjetas para arrastrar. Las rutinas son bandas rayadas, los hábitos con hora se marcan en el propio bloque y los hábitos de hoy se marcan en la barra lateral.
- **Roadmap:** se organiza en Fases → Módulos (temas + tareas) → Proyecto de fase.
- **Crear desde el contexto:** lo que se crea dentro de un proyecto, módulo o fuente ya lleva ese contexto.

## Cómo se generan

Las láminas se generan con VectorCraft, fuera del repo, en `~/Documentos/Rumbo-diseño/generador/`. Las vigentes salen de `build14.py` (tanda 1), `build15.py` (tanda 2), `build16.py` (Conocimiento) y `build17.py` (tanda 3). Con `--docs`, cada script copia sus PNG a esta carpeta.
